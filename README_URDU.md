# ادارہ خیر العباد — Phase 1 (حصہ 2)

Flutter + Riverpod + GoRouter، Feature-based Clean Architecture۔

## حصہ 1 میں تھا
Splash، Onboarding، Home، قرآن (114 سورتیں/30 پارے، کنز الایمان)، نماز کے اوقات، تسبیح، قبلہ، ترتیبات۔

## حصہ 2 میں نیا
| فیچر | تفصیل |
|---|---|
| **قرآن کی تحریر درست** | عربی کے لیے Amiri Quran فونٹ (بغیر bold)، بڑی لائن اسپیسنگ، عربی locale؛ ترجمے کا الگ فونٹ سائز |
| قرآن آڈیو | سورت منتخب کریں، آیت بہ آیت تلاوت (مشاری العفاسی)، Play/Pause/Next/Previous، دہرانا (آیت/سورت)، آیت پر ٹیپ کر کے وہیں سے سنیں |
| ماہانہ نماز کیلنڈر | پورے مہینے کے 6 اوقات، ہجری تاریخ، آج نمایاں |
| اذان کی ترتیبات | ہر نماز کا الگ سوئچ، فون موڈ/الارم موڈ، اذان سنیں، نوٹیفکیشن ٹیسٹ، اگلے 7 دن کے الارم |
| اسلامی کیلنڈر | اہم تاریخیں (باقی دن کے ساتھ) + رمضان سحر/افطار ٹائم ٹیبل |
| حدیث شریف | بخاری، مسلم، ابوداود، ترمذی، نسائی، ابن ماجہ؛ باب بہ باب؛ عربی + اردو/English؛ محدثین کے درجات؛ ہوم پر آج کی حدیث |
| قرآنی دعائیں | 14 دعائیں (آیات کے حوالوں سے)، متن+کنز الایمان ترجمہ |

## ماخذ (ہاتھ سے کچھ نہیں لکھا گیا)
- قرآن اور آڈیو: AlQuran Cloud (`quran-uthmani`، `ur.kanzuliman`، `en.ahmedraza`، `ar.alafasy`)
- حدیث: hadith-api (fawazahmed0) — jsDelivr CDN
- پہلی بار انٹرنیٹ چاہیے، پھر کیش ہو کر آف لائن بھی کھلتا ہے (آڈیو آن لائن ہی چلتی ہے)

## ابھی باقی (حصہ 3)
مسنون دعائیں/اذکار (مستند ڈیٹا سیٹ پہلے چنیں گے)، مضامین، آڈیو/ویڈیو لائبریری، اعلانات، پروفائل، زبان کا انتخاب
— ان کے لیے Firebase اور ایڈمن پینل (Phase 3 اور 5) درکار ہیں۔

## ضروری نوٹ
- پرانا ورژن (v1) انسٹال ہو تو **پہلے اسے ان انسٹال کریں**؛ GitHub ہر بار نئی ڈیبگ کلید سے سائن کرتا ہے، اس لیے اوپر اپڈیٹ نہیں ہوتا۔ (Phase 8 میں مستقل keystore لگے گی۔)
- اذان کے لیے: ایپ کھول کر اذان کی ترتیبات میں سوئچ آن کریں، نوٹیفکیشن اور "Alarms & reminders" کی اجازت دیں، بیٹری کو Unrestricted کریں۔
